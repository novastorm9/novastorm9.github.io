# What's ours, and must survive a merge from Dropbox

Tong works in Dropbox and doesn't use git. His copy is upstream for page copy,
product content, and figures. This repo keeps the history.

**Naming is unresolved.** This repo says WattsMIND Grid Agent, his says GridMind,
and the Cornell domain is gridmind.ece.cornell.edu. His diagram images have
GridMind baked into the pixels, so a text rename can't reach them. Settle it with
him rather than letting a merge decide.

## How to merge, safely

Never bulk-overwrite `app/` and patch afterwards — anything of ours that isn't
re-applied disappears silently. Instead:

1. `./merge/diff-dropbox.sh` — see what differs
2. `./merge/diff-dropbox.sh <path>` — read the actual diff for one file
3. Edit that file by hand, taking his changes and keeping ours
4. `npm run build:static`, check locally, commit

If a bulk rsync is genuinely worth it, preview it first:

    ./merge/diff-dropbox.sh --rsync-preview

Read every `*deleting` line before acting. Right now it would delete
`company/page.tsx` and `customers/page.tsx`, which may not be intended.
